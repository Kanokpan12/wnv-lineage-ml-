# wnv-lineage-ml

**Explainable machine learning identifies West Nile Virus lineages but not neuroinvasive outcome** (unpublished)  

This repository provides a complete computational workflow for studying West Nile virus (WNV) genomic and lineage prediction. The analyses integrate phylogenetics, machine learning to identify genetic signature.

## How to view the full results

The WNV final results dashboard provides an interactive interface for exploring model performance and genomic feature analyses. Users can navigate between four sections:

1. **Model Performance:** Compare genotype and phenotype classification models using accuracy, AUC, recall, and precision.
2. **Genotype: Position-wise:** Explore genomic position-level frequency differences, model gain, and SHAP importance.
3. **Genotype: Gene-level:** Examine the distribution of genomic signals and feature importance across viral genes.
4. **Phenotype Summary:** Evaluate WNND classification performance using permutation tests, repeated cross-validation, and descriptive genomic analyses.

**How to run:** Install the required Python dependencies, configure `OUT_DIR` in `04_app_visual.py` to point to the directory containing the pipeline output files, and launch the application using:

```bash
shiny run --reload 04_app_visual.py
```

Open the local URL provided in the terminal to view and navigate the dashboard. The application requires the output files generated by the preceding analysis scripts.

## Key Highlights
**Data labeling for the machine learning pipeline**
   Genetic Distance and Clinical Outcomes: WNV lineages were identified using phylogenetic analysis with IQ-TREE, and each viral sequence was assigned to a major lineage. These lineage labels were used as target variables for machine learning models to identify lineage-associated genetic signatures. For phenotypic classification, reported human cases with corresponding viral sequences were retrieved and assigned to their respective lineages to investigate associations between viral lineage and clinical outcomes.

**Model performance and best model selection**
For genotype classification using nucleotide-encoded features, all seven models achieved near-ceiling performance across all four metrics, with negligible separation between models (LGBM, GBC, ET, RF, XGB, AdaBoost, and DT). In contrast, phenotype (WNND) classification performance was markedly lower and more variable across both encoding schemes.

**Machine learning identify genetic signatures for genotype classification**
Gain-based feature importance showed an unevenly distributed pattern across the genome, with the largest importance values concentrated in NS1 and additional peaks scattered across E, NS3, and NS5, while most positions contributed negligible importance. SHAP analysis showed a similar distribution, with the highest per-position contributions occurring in NS1, NS2B, NS3, and NS4A, and comparatively lower, more diffuse contributions elsewhere across the genome.

**Permutation testing of WNV sequence-based phenotype prediction**
The result from permutation testing for nucleotide-encoded sequences, the observed mean AUC was 0.502, which was close to the null distribution (p = 0.465). Similarly, the amino-acid group-encoded model achieved an observed mean AUC of 0.523, which was also not significantly different from the permutation null distribution (p = 0.436). The distributions of accuracy, recall, positive predictive value (PPV), and F1 score across the 100 evaluations likewise indicated relatively limited classification performance for both encoding strategies. In summary, these results suggest that neither nucleotide- nor amino-acid group-based sequence encoding provided predictive performance that was distinguishable from that obtained with randomly shuffled phenotype labels.
